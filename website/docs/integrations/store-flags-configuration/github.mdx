# GitHub

## Overview
{info.longDescription ?? info.description}

:::info
GitHub has rate limits, be sure to correctly set your `PollingInterval` to avoid reaching the limit.

**If the rate limit is reached, the retriever will log an error and will stop polling until GitHub allows it again.**
:::
## Configure the relay proxy

To configure your relay proxy to use the {retrieverName} retriever, you need to add the following
configuration to your relay proxy configuration file:

```yaml title="goff-proxy.yaml"
# ...
retrievers:
  - kind: github
    repositorySlug: thomaspoignant/go-feature-flag
    path: config/flag/my-flags.yaml
# ...
```

| Field name       |    Mandatory     | Type   | Default  | Description                                                                                                                                                                                                                        |
|------------------|:----------------:|--------|----------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `kind`           |  <Mandatory />   | string | **none** | **Value should be `github`**.<br/>_This field is mandatory and describes which retriever you are using._                                                                                                                           |
| `repositorySlug` |  <Mandatory />   | string | **none** | The repository slug of the GitHub repository where your file is located _(ex: `thomaspoignant/go-feature-flag`)_.                                                                                                                  |
| `path`           |  <Mandatory />   | string | **none** | Path to the file inside the repository _(ex: `config/flag/my-flags.yaml`)_.                                                                                                                                                        |
| `branch`         | <NotMandatory /> | string | `main`   | The branch we should check in the repository.                                                                                                                                                                                      |
| `token`                    | <NotMandatory /> | string | **none** | GitHub token (PAT) used to access a private repository, you need the repo permission ([how to create a GitHub token](https://docs.github.com/en/free-pro-team@latest/github/authenticating-to-github/creating-a-personal-access-token)). Mutually exclusive with the GitHub App fields below. |
| `baseUrl`                  | <NotMandatory /> | string | `none`   | The base URL for the GitHub API. Use this for GitHub Enterprise or self-hosted instances _(ex: `https://github.acme.com/api/v3`)_. If not specified, defaults to `https://api.github.com`.                                         |
| `timeout`                  | <NotMandatory /> | string | `10000`  | Timeout in millisecond used when calling GitHub.                                                                                                                                                                                   |
| `githubAppId`              | <NotMandatory /> | int    | **none** | GitHub App ID. Required when using GitHub App authentication (see [GitHub App auth](#github-app-authentication)). Mutually exclusive with `token`.                                                                                 |
| `githubInstallationId`     | <NotMandatory /> | int    | **none** | GitHub App installation ID. Required when using GitHub App authentication.                                                                                                                                                         |
| `githubAppPrivateKey`      | <NotMandatory /> | string | **none** | PEM-encoded RSA private key for the GitHub App (inline). Use this or `githubAppPrivateKeyFile`, not both.                                                                                                                          |
| `githubAppPrivateKeyFile`  | <NotMandatory /> | string | **none** | Path to a PEM file containing the GitHub App private key. Useful for Kubernetes secret volume mounts. Takes precedence over `githubAppPrivateKey` if both are set.                                                                 |

## Configure the GO Module
To configure your GO module to use the {retrieverName} retriever, you need to add the following
configuration to your `ffclient.Config{}` object:

```go title="example.go"
err := ffclient.Init(ffclient.Config{
    PollingInterval: 3 * time.Second,
    Retriever: &githubretriever.Retriever{
        RepositorySlug: "thomaspoignant/go-feature-flag",
        Branch: "main",
        FilePath: "testdata/flag-config.goff.yaml",
        GithubToken: "XXXX",
        Timeout: 2 * time.Second,
    },
})
defer ffclient.Close()
```

| Field                |    Mandatory     | Description                                                                                                                                                                                                                               |
|----------------------|:----------------:|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`RepositorySlug`** |  <Mandatory />   | Your GitHub slug `org/repo-name`.                                                                                                                                                                                                         |
| **`FilePath`**       |  <Mandatory />   | The path of your file.                                                                                                                                                                                                                    |
| **`Branch`**         | <NotMandatory /> | The branch where your file is.<br/>Default: `main`                                                                                                                                                                                        |
| **`GithubToken`**          | <NotMandatory /> | GitHub token (PAT) used to access a private repository, you need the `repo` permission *([how to create a GitHub token](https://docs.github.com/en/free-pro-team@latest/github/authenticating-to-github/creating-a-personal-access-token))*. Mutually exclusive with the GitHub App fields. |
| **`BaseURL`**              | <NotMandatory /> | The base URL for the GitHub API. Use this for GitHub Enterprise or self-hosted instances _(ex: `https://github.acme.com/api/v3`)_. If not specified, defaults to `https://api.github.com`.                                                |
| **`Timeout`**              | <NotMandatory /> | Timeout for the HTTP call <br/>Default: 10 seconds                                                                                                                                                                                        |
| **`AppID`**                | <NotMandatory /> | GitHub App ID. Required when using GitHub App authentication (see [GitHub App auth](#github-app-authentication)). Mutually exclusive with `GithubToken`.                                                                                   |
| **`InstallationID`**       | <NotMandatory /> | GitHub App installation ID. Required when using GitHub App authentication.                                                                                                                                                                 |
| **`PrivateKey`**           | <NotMandatory /> | PEM-encoded RSA private key for the GitHub App (inline string). Use this or `PrivateKeyFile`, not both.                                                                                                                                    |
| **`PrivateKeyFile`**       | <NotMandatory /> | Path to a PEM file containing the GitHub App private key. Takes precedence over `PrivateKey` if both are set.                                                                                                                              |

## GitHub App authentication

Instead of a personal access token you can authenticate as a [GitHub App](https://docs.github.com/en/apps/creating-github-apps/about-creating-github-apps/about-creating-github-apps).
This removes the dependency on a user account and gives you fine-grained, repo-scoped permissions.

The retriever handles the full OAuth flow internally: it signs a short-lived JWT with the app's private key,
exchanges it for an installation token, caches the token, and refreshes it automatically before it expires.
No external service or sidecar is needed.

**GitHub App prerequisites:**
- Repository permission: **Contents: read-only** (Metadata: read is implicit).
- Install the app on the repository that holds your flag file.
- Generate a private key in the app settings and store it securely (e.g. a Kubernetes secret or AWS Secrets Manager).
- Note the **App ID** (shown on the app settings page) and **Installation ID** (visible in the URL of the app's installation settings: `https://github.com/organizations/<org>/settings/installations/<id>`).

### Relay Proxy Configuration

```yaml title="goff-proxy.yaml"
# ...
retrievers:
  - kind: github
    repositorySlug: myorg/my-flags-repo
    path: flags/config.yaml
    githubAppId: 12345
    githubInstallationId: 67890
    # Option A: path to a PEM file (recommended for Kubernetes secret mounts)
    githubAppPrivateKeyFile: /var/secrets/github-app.pem
    # Option B: inline PEM string — store the actual value in a secret manager
    # and inject it via an environment variable reference in your deployment.
    # githubAppPrivateKey: <contents of your .pem file>
# ...
```

:::note
`token` / `githubToken` and the GitHub App fields (`githubAppId`, `githubInstallationId`,
`githubAppPrivateKey` / `githubAppPrivateKeyFile`) are mutually exclusive.
Validation will reject a configuration that supplies both.
:::

### GO Module Configuration

```go title="example.go"
err := ffclient.Init(ffclient.Config{
    PollingInterval: 3 * time.Second,
    Retriever: &githubretriever.Retriever{
        RepositorySlug: "myorg/my-flags-repo",
        FilePath:       "flags/config.yaml",
        AppID:          12345,
        InstallationID: 67890,
        // Option A: path to a PEM file (recommended)
        PrivateKeyFile: "/var/secrets/github-app.pem",
        // Option B: inline PEM string loaded from a secret at runtime
        // PrivateKey: os.Getenv("GITHUB_APP_PRIVATE_KEY"),
    },
})
defer ffclient.Close()
```

## GitHub Enterprise / Self-hosted instances

If you are using a GitHub Enterprise or self-hosted instance, you can configure the `baseUrl` field to point to your instance's API endpoint.

### Relay Proxy Configuration

```yaml title="goff-proxy.yaml"
# ...
retrievers:
  - kind: github
    repositorySlug: myorg/myrepo
    path: config/flag/my-flags.yaml
    baseUrl: "https://github.acme.com/api/v3"
# ...
```

### GO Module Configuration

```go title="example.go"
err := ffclient.Init(ffclient.Config{
    PollingInterval: 3 * time.Second,
    Retriever: &githubretriever.Retriever{
        RepositorySlug: "myorg/myrepo",
        Branch: "main",
        FilePath: "config/flag/my-flags.yaml",
        BaseURL: "https://github.acme.com/api/v3",
        GithubToken: "XXXX",
    },
})
defer ffclient.Close()
```
